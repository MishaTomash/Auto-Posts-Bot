# 🤖 Auto-Posts-Bot

Telegram-бот, який веде канал замість автора. Користувач підключає свій канал, вказує канали-джерела, і бот сам збирає з них нові пости, відсіює рекламу, переписує текст через OpenAI у стилі каналу, підбирає ілюстрацію з Unsplash, якщо в оригіналі немає медіа, і публікує за розкладом.

Node.js · GramJS (MTProto) · OpenAI API · MongoDB · Telegram Stars

---

## Як це працює

```
Канали-джерела ──▶ GramJS (MTProto) ──▶ фільтр реклами ──▶ переписування ──▶ ілюстрація ──▶ канал користувача
                   читання як акаунт      gpt-4o-mini          gpt-4o-mini        Unsplash       за розкладом
```

Звичайний Bot API не може читати чужі канали, тому збір постів іде через MTProto від імені окремого Telegram-акаунта за допомогою GramJS. Бот підтримує фото, відео, аудіо й документи в постах-джерелах.

## Можливості

**Для користувача.** Покроковий майстер підключення каналу, керування джерелами й інтервалом публікацій, власний AI-промпт для стилю постів на платних тарифах, відкладені пости з автовидаленням, профіль з поточним тарифом і лімітами.

**Тарифи.** Чотири плани від Free до Business з різними лімітами каналів і постів на день. Оплата йде через Telegram Stars прямо в боті, а ліміти перевіряються перед кожною публікацією.

**Адмін-панель у самому боті.** Дашборд з кількістю користувачів і доходом за місяць, керування користувачами і їхніми каналами, зміна цін і лімітів тарифів без перезапуску, розсилки, підтвердження оплат і вивантаження логів.

## Технічні рішення

### AI-фільтр реклами

Кожен пост-джерело спершу проходить класифікатор на `gpt-4o-mini` з `temperature: 0` і відповіддю у форматі JSON: модель повертає `isAd`, рівень впевненості та коротку причину. Пост блокується лише при впевненості від 0.75, тож новини про компанії й огляди без заклику купити проходять, а промокоди, реферальні посилання й нативна реклама відсіюються. Якщо OpenAI недоступний, фільтр пропускає пост, а не зупиняє весь канал.

### Безпечний HTML для Telegram

Telegram приймає лише кілька HTML-тегів, а модель іноді повертає заголовки `<h1>` чи інші теги, через які повідомлення не надсилається. Перед публікацією відповідь проходить санітизацію: заголовки перетворюються на `<b>`, решта недозволених тегів видаляється, зайві порожні рядки стискаються.

### Структура бота

Обробники розділені на модулі за зонами відповідальності: `callbacks` з окремими модулями адмінки й каналів, `renderers`, які лише формують текст і клавіатури, `text_states` для багатокрокових діалогів і `services` з бізнес-логікою. Доступ до адмін-дій перевіряється окремим guard-модулем.

### Деплой

Після пушу в `main` GitHub Actions підключається до VPS через SSH, оновлює код, встановлює залежності й перезапускає бота під PM2. Адреса сервера і ключ зберігаються в GitHub Secrets.

## Локальний запуск

```bash
git clone https://github.com/MishaTomash/Auto-Posts-Bot.git
cd Auto-Posts-Bot
npm install
cp .env.example .env
```

У `.env` потрібні токен бота, рядок MongoDB, ключ OpenAI і дані MTProto-акаунта з [my.telegram.org](https://my.telegram.org). Рядок сесії акаунта генерується один раз:

```bash
node generate_session.js   # друкує TELEGRAM_SESSION для .env
npm start
```

```

├── bot/
│   ├── callbacks/            обробники кнопок: канали, адмінка, майстер, тарифи
│   │   ├── admin_modules/    дашборд, користувачі, тарифи, оплати, розсилки, логи
│   │   ├── channel_modules/  джерела, розклад, AI-промпт, відкладені пости
│   │   └── renderers/        тексти й клавіатури екранів
│   ├── handlers/             текстові повідомлення, оплати, багатокрокові діалоги
│   ├── keyboards/
│   └── middleware/           авторизація
├── services/                 збір постів, AI, зображення, підписки, розсилки
├── scheduler/                cron-задачі публікацій і видалень
├── models/                   User, Channel, Post, Plan, Payment, ScheduledPost, Log
└── config/plans.js           тарифи за замовчуванням
```
